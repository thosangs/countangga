# Countangga

Kalkulator tangga rumah berbasis satu halaman HTML. Menghitung estimasi jumlah kenaikan, tinggi anak tangga, kedalaman pijakan, posisi bordes, kebutuhan panjang, dan pemeriksaan kenyamanan dasar.

## Menjalankan lokal

Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
python3 -m http.server 8000
```

Lalu buka `http://localhost:8000`.

## Catatan

Hasil Countangga adalah estimasi geometri awal. Ukuran akhir perlu diperiksa oleh arsitek atau insinyur sipil karena aplikasi belum menghitung struktur, railing, tinggi bebas kepala, dan aturan bangunan setempat.
